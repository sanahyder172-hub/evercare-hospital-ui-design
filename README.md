# EverCare Hospital UI Design

A modern and user-friendly hospital website UI design created using Figma.

## Project Overview

EverCare Hospital is a clean and professional healthcare website concept designed to provide a simple and accessible user experience.

## Design Highlights

- Clean and professional healthcare interface
- User-friendly navigation
- Clear content structure
- Modern visual design
- Consistent layout and typography
- Responsive-style website design

- Visual Design
